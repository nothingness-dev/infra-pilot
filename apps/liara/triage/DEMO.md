# Five-minute triage demonstration (Task 05A)

**OFFLINE MOCK ONLY. No real Liara connection, authentication, approval, restart,
repair, scaling, deployment, or other infrastructure execution is demonstrated.**
Actual FastAPI validation, diagnosis, policy, approval lifecycle, and audits run
in-process. Only the observations and trusted identities/permissions are synthetic.
Contracts remain internal DRAFT v0.1, not official Liara APIs.

## Preparation

Install the module's `requirements.txt` using `README.md`; no activation, API key,
provider account, extra service, or frontend is needed. This demo intentionally
uses TestClient as a local test harness, not a production server interface.

```powershell
Set-Location -LiteralPath 'C:\git\shared\infra-pilot\apps\liara\triage'
.\.venv\Scripts\python.exe -m pytest -p no:cacheprovider
.\.venv\Scripts\python.exe -m infrapilot_triage.demo --mock
```

Without `--mock`, the CLI exits with usage status 2. The harness opens no network
listener, reads no credentials, writes no fixture/output files itself, and makes
no provider call. Its private app is not exported for Uvicorn. Two preinstalled
opaque sessions identify `MOCK-requester` and `MOCK-approver`; client headers and
body IDs cannot choose either. ACLs permit only the single MOCK target/restart,
with approval permission held by the different mock approver.

## Walkthrough

1. **0:00–1:00: report an HTTP 500.** Show
   `examples/mock_db_http500.request.json`. The user report motivates collecting
   this already supplied synthetic snapshot; the demo does not claim to collect
   observations from the natural-language report. HTTP diagnosis returns database
   connection failure ahead of generic HTTP error, linked to the actual log and
   status evidence. Missing CPU/RAM/latency remain missing.
2. **1:00–2:00: inspect recommendations.** The returned report includes a sensitive
   `review_database_configuration` recommendation and explicit limitations. Its
   status is `not_executed`. Recommendation IDs are not canonical policy operations.
   No permission, approval request, or infrastructure result follows from that label.
3. **2:00–3:00: demonstrate the guard.** The default HTTP authorize route returns
   503. A separate, explicitly selected MOCK restart intent from
   `mock_sensitive_pending.request.json` illustrates the approval process; it is
   not a proposed database remedy or a verified provider capability. In the private
   configured app, unapproved and pending authorization both return 403.
4. **3:00–4:00: show MOCK approval and replay.** Trusted Python code requests the
   pending approval, then separately calls the real gate using the mock approver.
   Granting approval still returns `allowed=false`. HTTP authorization consumes
   it once and returns `authorized_not_executed`; replay returns 403
   `approval_consumed`. No executor exists. Consumption is not execution success.
5. **4:00–5:00: compare slow/high CPU.** Show
   `examples/mock_cpu_latency.request.json` and its actual ranked report. CPU
   saturation is a heuristic supported by CPU and response-time observations;
   RAM/logs remain missing. Finish by showing
   `infrastructure_execution_performed=false` and the mock final approval state.

## Optional real loopback HTTP transport

For a live local HTTP demonstration of input-only diagnosis, use the existing
default application in a separate terminal:

```powershell
Set-Location -LiteralPath 'C:\git\shared\infra-pilot\apps\liara\triage'
.\.venv\Scripts\python.exe -m uvicorn infrapilot_triage.api:app --host 127.0.0.1 --port 8000 --no-access-log
```

From the presentation terminal:

```powershell
Invoke-RestMethod -Method Get -Uri 'http://127.0.0.1:8000/health'
foreach ($triageExample in @('mock_db_http500', 'mock_cpu_latency')) {
    $triageBody = Get-Content -LiteralPath ".\examples\$triageExample.request.json" -Raw -Encoding UTF8
    $triageReport = Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8000/internal/triage/diagnose' -ContentType 'application/json; charset=utf-8' -Body ([System.Text.Encoding]::UTF8.GetBytes($triageBody))
    $triageReport | ConvertTo-Json -Depth 20
}
```

Use Ctrl+C in the server terminal when finished. This default app remains
unconfigured for approvals (503), and `/health` asserts only process readiness.
Never serve the mock identity harness, expose a self-approval endpoint, or describe
these fixture results as actual Liara telemetry. The verified automated demo is
the in-process CLI; manual listener commands are provided for local presentation.
